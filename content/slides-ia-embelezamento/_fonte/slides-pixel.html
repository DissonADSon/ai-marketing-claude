05
A correção

Tire o eventodo navegador.

Server-side: o evento sai do seu servidor direto pra API da plataforma. Bloqueador de anúncio não alcança servidor.
1GTM Web coleta
2GTM Server recebe em domínio próprio
3Conversions API entrega ao Meta
06

Só que agoravocê contaduas vezes.

event_id igual nos dois lados.
07
O que levanta a nota

Advanced Matching.

Quanto mais sinal identificável você manda junto do evento, maior a chance de casar com a pessoa certa. Tudo hasheado, nada em texto puro.
+e-mail e telefone (SHA-256)
+cookies first-party _fbp / _fbc
+IP e user agent do servidor
+captura progressiva no formulário
